# Core Logic & Formula

## Match Format
pA vs pB (Player A vs Player B).

## Game Score Reduction Rule
A set that scores 7-5 gets -1 on both sides, resolving to 6-4.

A 7-6 (tiebreak) set does **not** resolve to 6-5. Per Director_2 resolution, the final resolve for a tiebreak set is always **6-4** for the winner, regardless of how long the tiebreak ran. See `resolved-questions.md`.

## Score-to-Points Breakdown Table

| Game Score | Points Awarded | Identifier |
|---|---|---|
| 0-2 | 2 Points | 1x |
| 3-4 | 4 Points | 2x |
| 5 | 7 Points | 3x |
| 6 | 10 Points | 4x |

The `1x / 2x / 3x / 4x` column is an identifier for the score section — **not** a multiplier. See `resolved-questions.md`.
